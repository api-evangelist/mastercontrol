# MasterControl

> MasterControl builds cloud quality management (QMS) and manufacturing execution (MES) software
> for regulated industries — pharmaceutical, biotechnology, medical device, CRO/CDMO, and food and
> beverage manufacturers. The platform covers document control, training, CAPA, change control,
> audit, supplier quality, electronic batch records and production records, and is built to support
> FDA 21 CFR Part 11, EU MDR, GDPR and HIPAA obligations. This file is generated by API Evangelist
> from public sources; MasterControl does not publish an llms.txt of its own.

## API surface

MasterControl exposes RESTful APIs for two product lines through a separately licensed **API
Toolkit**:

- **Qx (Quality Excellence) RESTful API** — create, modify, get and delete quality-system data.
- **Mx (Manufacturing Excellence) RESTful API** — create, modify, get and delete manufacturing and
  production-record data.

The APIs are used to integrate MasterControl with ERP, CRM, MES, PDM and document repositories.
MasterControl also offers Integration Services built on the API Toolkit and MuleSoft iPaaS.

**Access is gated.** A site must purchase an API license before the API Toolkit can be used, and
the API reference is served as a Swagger UI from the customer's own tenant path on a regional
service host (`https://mx.<region>.svc.mastercontrol.com/<company>/swagger-ui/index.html`) rather
than from a public developer portal. There is no anonymous OpenAPI, GraphQL SDL, MCP server, A2A
agent card, first-party SDK, or public Postman collection.
